# studentportfolio

Collection of 10 distinct, responsive student portfolio designs and templates with customizable dynamic editor support.

## Overview

This repository contains 10 independent portfolio projects (`student-portfolio-01` to `student-portfolio-10`). Each project has its own distinct public UI, component tree, animation style, sample profile, storage configuration, and site identity.

### Included Designs

1. **student-portfolio-01**: Editorial Index (hover preview index)
2. **student-portfolio-02**: Bento Studio (spotlight tiles)
3. **student-portfolio-03**: Swiss Grid (grid rows)
4. **student-portfolio-04**: Bold Poster (poster blocks)
5. **student-portfolio-05**: Personal Journal (accordion stories)
6. **student-portfolio-06**: Scroll Chapters (parallax chapters)
7. **student-portfolio-07**: Split Profile (timeline feed)
8. **student-portfolio-08**: Developer Terminal (command tabs)
9. **student-portfolio-09**: Playful Board (draggable cards)
10. **student-portfolio-10**: Project Gallery (gallery carousel)

## Getting Started

See [START-HERE.md](START-HERE.md) and [DESIGNS.md](DESIGNS.md) for detailed setup and design documentation.

### Quick Setup

Choose any portfolio folder (e.g., `student-portfolio-01`):

```bash
cd student-portfolio-01
pnpm install
pnpm run build
node scripts/setup-local.mjs
pnpm run dev
```
